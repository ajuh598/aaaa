# 웹 오목 마스터 (Web Omok Master)

브라우저에서 5단계 난이도의 AI(백)와 겨루는 15×15 오목 게임입니다. 빌드 과정 없이 정적 파일만으로 동작합니다.

## 실행

Web Worker는 `file://`에서 막히는 경우가 많으므로 로컬 서버로 여는 것을 권장합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속. (`index.html`을 바로 열어도 동작하지만, 이때는 AI가 메인 스레드에서 계산합니다.)

## 기능

- **기본 규칙**: 15×15, 흑(플레이어) 선공, 가로/세로/대각선 5목 승리
- **룰 설정**
  - 렌주룰: 흑의 삼삼·사사·장목 금수 (진짜 열린 3 판정 포함, 5목 완성은 금수보다 우선), 백은 장목도 승리
  - 렌주룰을 끄면 장목(6목 이상) 승리 인정 여부 선택
  - 한 수 제한 시간: 무제한 / 15 / 30 / 60초 (초과 시 패배)
  - 금수 위치 표시(×), 수순 번호 표시
- **게임 화면**: 현재 턴, 남은 시간, 상태 알림(금수 경고, 백의 4 경고 등), 항복
- **결과 화면**: 승리/패배/무승부 팝업, 다시 하기, 판 확인하기, 메인으로
- **전적**: 난이도별 승/패/무와 승률, 최근 30경기 기록 (localStorage)
- **반응형**: PC는 마우스 호버 미리보기 + 클릭, 모바일은 같은 자리를 두 번 탭해 착수(오착 방지), 키보드(방향키 + Enter)도 지원
- 무르기 기능은 없습니다.

## AI 난이도

| 단계 | 방식 |
|---|---|
| 1. 쉬움 | 1수 앞 패턴 평가 + 무작위성. 5목·4목 방어를 자주 놓침 |
| 2. 보통 | 2수 앞 미니맥스, 점수에 노이즈와 가끔 차선택 |
| 3. 어려움 | 미니맥스 + 알파베타, 4수 앞, 위협(4/열린3) 강제 응수 |
| 4. 매우 어려움 | 6수 앞 + VCF(연속 4) 공격 수읽기 + 상대 VCF 방어 |
| 5. 익스트림 | 반복 심화 최대 12수(4초 제한) + 트랜스포지션 테이블 + 깊은 VCF 공방 |

평가 함수는 9칸 라인 패턴 테이블(3⁸ = 6561가지, 열린4/막힌4/열린3/닫힌3/2 분류)을 착수마다 증분 갱신합니다.
AI 연산은 Web Worker에서 실행되어 화면이 멈추지 않습니다.

## 구조

```
index.html          화면 마크업 (메인 / 게임 / 모달)
css/style.css       스타일 (라이트/다크 대응)
js/rules.js         승패 판정, 렌주룰 금수 판정
js/ai.js            AI 엔진 (패턴 테이블, 알파베타, VCF, 난이도 설정)
js/ai-worker.js     AI Web Worker
js/main.js          UI, 캔버스 렌더링, 입력, 타이머, 전적
tests/run-tests.js  규칙/AI 테스트 (node tests/run-tests.js)
```
