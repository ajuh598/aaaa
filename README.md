# 웹 오목 마스터 (Web Omok Master)

브라우저에서 전용 오목 AI **AXIOM**(백)과 겨루는 15×15 오목 게임입니다. 빌드 과정 없이 정적 파일만으로 동작합니다.

## 실행

Web Worker는 `file://`에서 막히는 경우가 많으므로 로컬 서버로 여는 것을 권장합니다.

```bash
python3 -m http.server 8000
```

브라우저에서 `http://localhost:8000` 접속. (`index.html`을 바로 열어도 동작하지만, 이때는 AI가 메인 스레드에서 계산합니다.)

## 기능

- **기본 규칙**: 15×15, 흑(플레이어) 선공, 가로/세로/대각선 5목 승리
- **룰 설정**
  - 렌주룰: 흑의 삼삼·사사·장목 금수 (진짜 열린 3 판정 포함, 5목 완성은 금수보다 우선), 백은 장목도 승리
  - 렌주룰을 끄면 장목(6목 이상) 승리 인정 여부 선택
  - 금수 위치 표시(×), 수순 번호 표시
- **게임 화면**: 현재 턴, 상태 알림(금수 경고, 백의 4 경고 등), 항복 (제한 시간 없음)
- **결과 화면**: 승리/패배/무승부 팝업, 다시 하기, 판 확인하기, 메인으로
- **전적**: 난이도별 승/패/무와 승률, 최근 30경기 기록 (localStorage)
- **반응형**: PC는 마우스 호버 미리보기 + 클릭, 모바일은 같은 자리를 두 번 탭해 착수(오착 방지), 키보드(방향키 + Enter)도 지원
- 무르기·제한 시간 기능은 없습니다.

## AXIOM

AXIOM은 이 게임 전용 오목 AI입니다. 버전은 `AXIOM-v1`, `AXIOM-v2` …처럼 올라가며, 게임은 `js/axiom-model.js`에 들어 있는 모델을 사용합니다.

### 학습하고 발전하는 방식

1. **자체 대국 학습** (`training/train.js`)
   - 현재 모델이 스스로 수천 판을 둡니다(초반에는 무작위 탐험을 섞음). 각 국면의 특징과 그 판의 최종 승패를 모읍니다.
   - 특징은 둘 차례인 쪽과 상대 각각의 빈칸 형태 개수(열린2, 막힌3, 열린3, 4, 열린4 …), 삼삼·사삼 자리, 템포로 모두 19개입니다.
   - 국면 특징으로 최종 승패를 예측하도록 평가 함수 가중치를 회귀(Texel 방식)로 조정해 후보를 만듭니다.
2. **평가 대국**: 후보와 현재 모델이 같은 오프닝으로 흑백을 바꿔 가며 수백 판을 둡니다. 우월할 확률(LOS)이 90% 이상일 때만 채택합니다. 이 과정을 여러 세대 반복합니다.
3. **버전 승격**: 최종 모델을 출발 모델과 다시 대국해 승점과 Elo를 기록합니다. 기준을 통과하면 `training/models/axiom-vN.json`으로 저장하고 `--promote`로 게임에 적용합니다. 통과하지 못하면 적용하지 않습니다.
4. **실제 플레이어 대국에서의 학습**
   - 브라우저에서 둔 대국은 기기에 저장됩니다(localStorage).
   - AXIOM은 그 대국에서 자신이 둔 수(대국 마지막 20수 범위)를 승패와 함께 기억합니다. 같은 국면(회전·대칭 포함)이 다시 나오면 진 수는 덜 두고 이긴 수는 더 둡니다.
   - AXIOM 정보 화면의 **대국 기록 내보내기**로 받은 JSON을 `--human`으로 학습에 넣을 수 있습니다. 그러면 평가 함수 학습 데이터와 모델의 오프닝 북에 반영되어, 다음 버전부터 모든 플레이어에게 적용됩니다.

### 학습 명령어

```bash
node training/train.js                                  # 현재 모델 → 다음 버전 후보 (적용 안 함)
node training/train.js --promote                        # 평가 통과 시 게임에 적용
node training/train.js --human axiom-games.json --promote   # 플레이어 대국 기록 포함
node training/evaluate.js --a current --b baseline      # 두 모델 평가 대국
node training/promote.js training/models/axiom-v2.json  # 저장된 모델을 게임에 적용
```

주요 옵션: `--gens`(세대 수), `--games`(세대당 자체 대국 수), `--pairs` / `--max-pairs`(순차 평가의 한 번 추가량 / 최대 오프닝 수, 오프닝마다 흑백 교대 2판), `--data-depth` / `--gate-depth` / `--eval-depth`(자체 대국 / 세대 평가 / 최종 평가 탐색 깊이), `--los`(채택 기준, 기본 0.95).
학습 기록은 `training/logs/`에, 버전별 모델은 `training/models/`에 남습니다.

### 난이도 (AXIOM의 5단계 강도)

| 단계 | 방식 |
|---|---|
| 1. 쉬움 | 1수 앞 패턴 평가 + 무작위성. 5목·4목 방어를 자주 놓침 |
| 2. 보통 | 2수 앞 미니맥스, 점수에 노이즈와 가끔 차선택 |
| 3. 어려움 | 미니맥스 + 알파베타, 4수 앞, 위협(4/열린3) 강제 응수 |
| 4. 매우 어려움 | 6수 앞 + VCF(연속 4) 공격 수읽기 + 상대 VCF 방어 |
| 5. 익스트림 | 반복 심화 최대 12수(4초 제한) + 트랜스포지션 테이블 + 깊은 VCF 공방 |

보통 이상에서는 학습된 평가 함수와 경험(오프닝 북 + 내 대국 기억)이 함께 쓰입니다. 연산은 Web Worker에서 실행되어 화면이 멈추지 않습니다.

## 구조

```
index.html          화면 마크업 (메인 / 게임 / 모달)
css/style.css       스타일 (라이트/다크 대응)
js/rules.js         승패 판정, 렌주룰 금수 판정
js/axiom-model.js   AXIOM 런타임 모델 (자동 생성: 가중치, 학습/평가 기록, 오프닝 북)
js/ai.js            AXIOM 엔진 (패턴 테이블, 학습 평가 함수, 알파베타, VCF, 경험 반영)
js/ai-worker.js     AXIOM Web Worker
js/main.js          UI, 캔버스 렌더링, 입력, 전적, 경험 저장/내보내기
training/           자체 대국 학습·평가 파이프라인 (Node, worker_threads 병렬)
  train.js            학습 → 평가 → 버전 생성
  evaluate.js         모델 간 평가 대국
  promote.js          모델을 게임에 적용
  models/             버전별 모델 (axiom-v1.json …)
  logs/               학습 기록
tests/run-tests.js  규칙/AI/AXIOM 테스트 (node tests/run-tests.js)
```
